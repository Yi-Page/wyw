播放器分屏面板 · 界面示意

组件与设置页完全一致：SettingsList / SettingsSection / SettingsSliderTile / SelectTile / SettingsTile； 页签条照收藏页的胶囊指示器 TabBar；选择项一律下拉（SelectTile），不用一排按钮。
面板契约 = 5 个 tab（选集 / 弹幕 / 画面 / 播放 / 更多），见 docs/player-split-panel-plan.md §1.3。
